# Мониторинг цен

Этот файл подключает общий навык проекта к Claude Code. Перед выполнением прочитай [AGENTS.md](../../../AGENTS.md) из корня проекта, затем полностью прочитай [.agents/skills/tracker/SKILL.md](../../../.agents/skills/tracker/SKILL.md) и выполни его инструкции.

Основной файл содержит процедуру, зависимости и критерии завершения. Пути проекта отсчитывай от корня с AGENTS.md. Если основной файл недоступен, сообщи об этом и остановись.
