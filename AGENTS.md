# Правила работы в проекте

Перед сбором или сравнением цен прочитай [KNOWLEDGE.md](KNOWLEDGE.md): там находятся модель, требуемая комплектация и часовой пояс проекта.

## Навыки проекта

Для мониторинга цен используй [.agents/skills/tracker/SKILL.md](.agents/skills/tracker/SKILL.md), для извлечения цены одной карточки — [.agents/skills/extract-price/SKILL.md](.agents/skills/extract-price/SKILL.md). Открывай локальные файлы даже при наличии одноимённых навыков в общем каталоге: версии этого проекта имеют приоритет.

Пути проекта отсчитывай от папки с этим AGENTS.md. Настройки Telegram находятся в корневом `.env`; значения сохраняй только локально и передавай скрипту через окружение процесса.

## Сохранение кода

После каждого изменения проекта сохраняй весь актуальный код и связанные файлы в https://github.com/igorshpindler-tech/vibecoding-claudecode-project-388: создавай коммит и отправляй его в GitHub. Сохранение завершено после подтверждения успешной отправки. При ошибке отправки сообщи о ней пользователю и сохрани изменения локально.
