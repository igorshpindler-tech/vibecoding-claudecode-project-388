# Знания проекта

## Товар и комплектация

Цель — мониторинг цен на снегоуборщик Daewoo DAST 3421Li в комплекте с зарядным устройством и аккумуляторными батареями.

В сравнение включаются только предложения с подтверждённой целевой комплектацией. Количество и ёмкость батарей пока не заданы. Неподтверждённую комплектацию отмечай как причину пропуска предложения.

## Регион и время

Часовой пояс проекта — `Europe/Moscow`. Для магазина «Петрович» используется московский сайт. Допустимые сайты и правила получения цен определяет локальный навык `extract-price`.

## Данные и правила уведомлений

Ежедневные результаты хранятся в [igorshpindler-tech/tracker-data](https://github.com/igorshpindler-tech/tracker-data). JSON-файлы в корне этого проекта — локальные копии прогонов; их наличие не подтверждает публикацию в репозитории данных.

Единственный источник правил значимости изменений — актуальный [KNOWLEDGE.md в tracker-data](https://github.com/igorshpindler-tech/tracker-data/blob/main/KNOWLEDGE.md). Перед сравнением прочитай внешний файл и зафиксируй его SHA. Локальный KNOWLEDGE.md содержит параметры проекта и не заменяет внешний файл правил.

Расписание не создаётся самим наличием ежедневных файлов. Сбор запускается по запросу пользователя либо отдельно настроенным расписанием.
